# 対戦型スネイク / battle-snake

石の道を残し、ダッシュとジャンプで切り抜けるPC向けサバイバルゲーム。制作版v3.1の独立した記録・配布版です。

[CPU専用デモで遊ぶ](https://dybo46.github.io/battle-snake/) ／ [遊び方](https://dybo46.github.io/battle-snake/help.html) ／ [自己設置方法](SELF-HOSTING.md)

標準28×26マス（内側26×24）。6本／11本先取、乱戦・プレイヤー協力VS CPU・ランダム2対2チーム。ダッシュは無制限、慣性あり。ジャンプ中は石を残さず、空中で直角に曲がれます。着地先の石はアウト。

- 10段階CPU、15性格と全CPU共通の抽選候補。平均・丁寧・ラーメン・攻撃・連携・ストーカー・酔いどれなど。
- 62スキンと81背景。ランダムスキン、対応背景の自動選択、背景固定。
- 歩行・ジャンプ・衝突・開始が各15種類の自作電子音。種類・音量を試聴して調整。
- CPU観戦の終了後「ひたすら観戦を続ける」で同じルールの次戦を繰り返します。結果表示6秒、試合ごとにランダムを再抽選。

## 2つの構成

| フォルダー | 内容 |
|---|---|
| docs | GitHub PagesのCPU専用デモ。ブラウザだけで動作。ネット待受・チャットはありません。 |
| self-host | 利用者が自分のサーバーへ設置するネット対戦版。6人の部屋、チャット、最大4人対戦、誰でも同時対戦。 |
| record | 公開用の照合・通信確認記録。 |

作者の運用サーバーの接続先や入口リンクは含みません。私用版と自動同期しません。

## 手元で試す

Node.js 24以上で `npm run demo` → http://127.0.0.1:8794/battle-snake/ 。外部パッケージ不要。名前はデモ内の表示用です。

操作：矢印／WASDで曲がる、左クリック／Shiftでダッシュ、右クリック／B／Spaceでジャンプ。盤面の左クリックで操作に入り、Esc／Enter／Backspaceで解除します。画面右でルール・見た目・音を調整できます。設定は永続保存しません。

検証は `npm test` と `npm run test:self-host`。利用条件は [LICENSE-STATUS.md](LICENSE-STATUS.md)、公開手順は [PAGES.md](PAGES.md)、確認結果は [VERIFICATION.md](VERIFICATION.md) を参照してください。
