# 自作の電子効果音

対戦型スネイク v0.3用に本プロジェクトで合成した60候補です。既存ゲームの録音・抽出音、外部の音源、第三者のサンプルは使用していません。ウイッツのSEそのものを収録したものではなく、「キュイ」「ピュイ」等のユーザーの音のイメージに合わせた新しい音です。

- 歩く音15種：短い周波数スイープ、パルス/三角/正弦/FM等。ゲームではマス移動ごとに再生し、ダッシュで再生間隔が速くなります。
- ジャンプ15種：滑らかな/段階的な上昇音、丸い音、透明感のある音等。
- 衝突15種：下降する短い電子音、丸いつぶれ音、デジタル音等。車の衝突等の実録音は使用していません。
- ラウンド開始15種：短い合図音、澄んだピン音、2〜3音の合図等。

44.1kHz/16bit/モノラルWAV。原本は共通資料素材の09_音資料/battle-snake/v0.3-originals-r2、試作初版はv0.3-originalsに別保存。採用音の定義はpublic/sound-bank.js、生成はscripts/generate-sounds.mjs、名前・パラメーター・SHA256・長さ・ピーク/RMSはmanifest.json。実行用コピーをこのフォルダーへ収録。

位相連続の発振、帯域を抑えたパルス、短い立ち上がり/立ち下がり、DC除去とピークの余裕を設けています。全候補の数値検査とブラウザーでのデコード/試聴動作を確認。耳での好みはゲーム内で聴き比べて選んでください。
